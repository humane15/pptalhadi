Bab 01

Latar Belakang & Urgensi

Perkembangan TIK meningkatkan risiko ancaman siber, khususnya SQL Injection yang mengancam kerahasiaan dan integritas basis data aplikasi web.

NIDS bertindak sebagai sensor di lapisan jaringan untuk memantau lalu lintas secara real-time.

Solusi: mengembangkan 30 custom signature yang lebih fokus, ringan, akurat, dan efisien dibanding aturan bawaan.

Masalah NIDS Konvensional

Default rules Snort

1

Database signature generik sangat banyak (~150 rules).

2

Beban komputasi tinggi & pemrosesan paket lambat.

3

Alokasi memori RAM besar (~20 MB).

4

False Positive tinggi (~25%) & kurang responsif pada serangan termodifikasi.

Bab 02

Dasar Teori Kunci

NIDS

Menganalisis paket data di lapisan jaringan secara real-time dan membandingkannya dengan basis data pola (signature).

Signature-Based

Pencocokan pola karakter/hex unik (pattern matching) pada isi paket. Akurasi tinggi & hemat komputasi dibanding anomaly-based.

Snort NIDS

Engine IDS open-source berbasis packet sniffer/logger dengan arsitektur pcap dan PCRE (regex).

SQL Injection

Penyuntikan kueri SQL berbahaya pada parameter input (GET/POST) untuk mengeksploitasi basis data target.

Bab 05

Kesimpulan

1

NIDS dengan 30 custom rules (10 kategori) berhasil dirancang & diimplementasikan untuk mendeteksi serangan SQLMap.

2

Rata-rata Detection Rate mencapai 83.83% di seluruh level keamanan DVWA.

3

Custom rules unggul atas default rules: Detection Rate +13.83% dan False Positive turun 17%.

4

Sumber daya jauh lebih efisien dengan penghematan RAM hingga 85% (~3 MB vs ~20 MB).

5

Konsep Defense-in-Depth berjalan: NIDS sebagai peringatan dini, Prepared Statement sebagai benteng akhir.

Bab 05

Saran Penelitian

Menambahkan rule deteksi untuk fungsi SQL lanjutan: RLIKE, REGEXP, dan kondisional IF.

Menguji dengan tools SQLi lain (Havij, jSQL Injection) untuk menguji generalisasi rule.

Pengujian di lingkungan produksi jaringan riil untuk mengukur False Positive aktual.

Mengintegrasikan Snort dengan SIEM untuk pemantauan terpusat.

Mengembangkan mekanisme auto-update rules berbasis Threat Intelligence feed.
